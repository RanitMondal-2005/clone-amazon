# Amazon.com Homepage Clone 🛒

A fun, hands-on learning project replicating the Amazon layout to master semantic HTML5 structure, CSS Grid, Flexbox, and responsive web design.

This is my very first frontend practice project! It is built entirely using pure HTML and CSS—no JavaScript, no frameworks, and no external libraries.

## 🛠️ Tech Stack & Features
*   **HTML5:** Learning semantic structures like headers, navigation bars, and product containers.
*   **CSS3:** Practicing color styling, hover animations, and font adjustments.
*   **Flexbox & Grid:** Figuring out how to use CSS Grid for the product boxes and Flexbox for the navigation bar alignment.

## 📂 Project Setup
Since this is a local practice project, all components are contained in the main files:
*   `index.html` — The core layout and structure of the page.
*   `style.css` — The styling, grid layouts, and box alignments.

## 🧠 What I Learned
*   **Layout Logic:** Figuring out when to use Flexbox versus CSS Grid.
*   **Box Model:** Mastering padding, margins, and borders to get things pixel-perfect.
*   **File Management:** Learning how to link local styles and keep code organized.

## 🔧 How to Run It Locally
1. Clone or download this repository to your computer.
2. Double-click the `index.html` file to open it instantly in your web browser.
